## Course Takeaways

Across the course, I learned to treat evaluation not as a single benchmark score, but as a design problem involving task construction, validity, error analysis, and careful interpretation. The main takeaway is that reliable AI safety evaluation depends on the full system around the model — benchmarks, prompts, judges, tools, statistics, and research judgment — and that weak evaluation design can create false confidence as easily as it can reveal real capability or risk.
